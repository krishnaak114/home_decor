# 🏠 Home Decor AI Platform
## MVP Technical Specification (8-Week Solo Launch)

**Version:** 1.0 MVP  
**Developer:** Solo (full-time, 8 weeks)
**Timeline:** 8 weeks  
**Scope:** 10-12 screens, focused e-commerce platform with AI room visualization  
**Philosophy:** Launch minimal but complete → iterate based on real user feedback

---

## Technology Stack - MVP Focused

### **Frontend**
- **Framework:** Next.js 15 + React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State:** Zustand (lightweight)
- **Hosting:** Vercel (automatic deployments)

### **Backend**
- **Framework:** FastAPI (Python 3.11)
- **Database:** PostgreSQL 15
- **Cache:** Redis (sessions + product cache)
- **Hosting:** DigitalOcean App Platform or AWS

### **AI Integration**
- **Claude 3.5 Haiku API** (room photo analysis)
- **Cost:** ~₹2-3 per design generation

### **Payment**
- **Stripe** (cards)
- **Razorpay** (UPI, wallets)

### **File Storage**
- **AWS S3** (product photos, room uploads)
- **CloudFront CDN** (image delivery)

## Database Schema (MVP Only)

### **Table 1: Users**
```sql
CREATE TABLE users (
  id UUID PRIMARY KEY,
  email VARCHAR(255) UNIQUE,
  phone VARCHAR(15) UNIQUE,
  name VARCHAR(255),
  auth_provider VARCHAR(50), -- 'google' or 'phone'
  design_credits INTEGER DEFAULT 10, -- Free credits on signup, decremented per design
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);
```

### **Table 2: Products**
```sql
CREATE TABLE products (
  id UUID PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  category VARCHAR(100), -- 'sofa', 'table', 'lamp', 'art', etc.
  price DECIMAL(10, 2),
  image_url VARCHAR(500),
  design_styles TEXT[], -- JSON array: ['modern', 'luxury']
  description TEXT,
  room_type VARCHAR(50) DEFAULT 'living_room', -- MVP: living_room only
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);
```

### **Table 3: Designs (Room designs generated by AI)**
```sql
CREATE TABLE designs (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  room_photo_url VARCHAR(500),
  wall_length DECIMAL(5, 2), -- Room wall length (meters/feet)
  wall_colors VARCHAR(500), -- Existing wall colors in room
  room_description TEXT, -- User's description of room
  ai_response_json TEXT, -- Full Claude API response stored
  design_style VARCHAR(100), -- 'modern', 'luxury', 'minimalist'
  color_palette JSON, -- ['#2C3E50', '#ECF0F1', '#E74C3C']
  suggested_products UUID[], -- Array of product IDs
  is_saved BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP,
  updated_at TIMESTAMP,
  
  INDEX idx_user_id (user_id),
  INDEX idx_created_at (created_at)
);
```

### **Table 4: Cart Items**
```sql
CREATE TABLE cart_items (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  product_id UUID REFERENCES products(id),
  quantity INT DEFAULT 1,
  added_at TIMESTAMP,
  
  INDEX idx_user_id (user_id)
);
```

### **Table 5: Orders**
```sql
CREATE TABLE orders (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  total_amount DECIMAL(10, 2),
  status VARCHAR(50), -- 'pending', 'paid', 'shipped', 'delivered'
  delivery_address TEXT,
  payment_method VARCHAR(50), -- 'stripe', 'razorpay'
  payment_id VARCHAR(255), -- External payment ID
  created_at TIMESTAMP,
  updated_at TIMESTAMP,
  
  INDEX idx_user_id (user_id),
  INDEX idx_status (status)
);
```

### **Table 6: Order Items**
```sql
CREATE TABLE order_items (
  id UUID PRIMARY KEY,
  order_id UUID REFERENCES orders(id),
  product_id UUID REFERENCES products(id),
  quantity INT,
  price_at_purchase DECIMAL(10, 2),
  
  INDEX idx_order_id (order_id)
);
```

### **Table 7: Product Reviews** (Basic trust-building)
```sql
CREATE TABLE product_reviews (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  product_id UUID REFERENCES products(id),
  rating INT CHECK (rating >= 1 AND rating <= 5),
  comment TEXT,
  created_at TIMESTAMP,
  updated_at TIMESTAMP,
  
  INDEX idx_product_id (product_id),
  INDEX idx_user_id (user_id)
);
```

### **Table 8: Design Styles (Reference data)**
```sql
CREATE TABLE design_styles (
  id UUID PRIMARY KEY,
  name VARCHAR(100) UNIQUE, -- 'modern', 'luxury', 'minimalist'
  color_palette JSON, -- ['#color1', '#color2', '#color3']
  description TEXT,
  is_active BOOLEAN DEFAULT TRUE
);
```

### **Table 9: Sessions (Redis would be preferred, but can use DB)**
```sql
CREATE TABLE sessions (
  session_id VARCHAR(500) PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  token TEXT,
  expires_at TIMESTAMP,
  created_at TIMESTAMP,
  
  INDEX idx_expires_at (expires_at)
);
```

## API Endpoints - MVP Only

### **Authentication**

**POST /auth/google**
- Request: `{ id_token: "..." }`
- Response: `{ access_token, user }`
- Purpose: Google login

**POST /auth/phone/request-otp**
- Request: `{ phone: "+91..." }`
- Response: `{ message: "OTP sent" }`
- Purpose: Send OTP to phone

**POST /auth/phone/verify-otp**
- Request: `{ phone: "+91...", otp: "123456" }`
- Response: `{ access_token, user }`
- Purpose: Verify OTP and login

**POST /auth/logout**
- Purpose: Logout user

### **Room Design (Core Feature)**

**POST /designs/generate**
- Request: 
  ```json
  {
    "room_photo_url": "s3://...",
    "wall_length": 5.5,
    "wall_colors": "Beige, White",
    "room_description": "Modern, bright living room with lots of natural light",
    "selected_products": ["uuid-sofa-123", "uuid-rug-456"],  // Optional - user's selected items
    "category": "sofa"  // Optional - what user is looking for
  }
  ```
- Response:
  ```json
  {
    "design_id": "uuid",
    "style": "modern",
    "colors": ["#2C3E50", "#ECF0F1"],
    "suggested_products": [
      { "id": "uuid-sofa-123", "name": "Modern Grey Sofa", "price": 25000 },
      { "id": "uuid-rug-456", "name": "Beige Rug", "price": 5000 }
    ]
  }
  ```
- Purpose: **CORE - Call Claude API with user input → get design**
- **Key features:**
  - **Requires login:** Must be authenticated to track credits
  - **Credit check:** Returns error if user has 0 credits remaining
  - **Credit deduction:** Decrements user's design_credits by 1 on successful generation
  - User provides wall_length, wall_colors, room_description → AI doesn't waste time analyzing
  - User selects specific products (optional) → AI designs with those items
  - If no products selected → AI picks best from inventory based on room details
  - **Faster processing (~8-12 seconds)**

**GET /designs/{id}**
- Response: Full design with room image + metadata
- Purpose: Retrieve saved design

**GET /designs/user/me**
- Response: `[{ ...design }, ...]`
- Purpose: List user's saved designs

**DELETE /designs/{id}**
- Purpose: Delete saved design

**GET /products/{category}/variations**
- Query: `?wall_color=beige&count=5`
- Response:
  ```json
  {
    "variations": [
      { "id": "uuid-sofa-1", "name": "Modern Grey Sofa", "price": 25000, "image_url": "..." },
      { "id": "uuid-sofa-2", "name": "Luxury Beige Sofa", "price": 35000, "image_url": "..." },
      { "id": "uuid-sofa-3", "name": "Minimalist White Sofa", "price": 20000, "image_url": "..." }
    ]
  }
  ```
- Purpose: **Get product alternatives for fast swapping (8-12 seconds)**
- **How it works:** User selects variation → AI regenerates design with new product → Returns updated image
- **Credit deduction:** Decrements 1 credit per swap (same as new design generation)

**POST /designs/{id}/regenerate-style**
- Request: `{ style: "luxury" }` or `{ style: "modern" }`
- Purpose: Regenerate design in different style (all items swapped automatically)
- **Fast:** Only regenerates the AI suggestions, reuses room photo
- **Credit deduction:** Decrements 1 credit per style regeneration

## Error Handling

**If Claude API fails:**
- Show template designs
- Don't block user

**If S3 upload fails:**
- Retry 3 times
- Show error message
- Don't proceed

**If payment fails:**
- Show clear error
- Don't charge customer
- Allow retry
